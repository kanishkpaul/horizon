# Interchange schemas

Versioned case, evidence snapshot, result manifest, and capability formats will live
here beginning with M1. No schemas are implemented yet. Define stable IDs, units,
states, schema versions, compatibility, and invalid-input behavior before generating
Rust or TypeScript boundary types. Keep personal data and provider SDK objects out
of the contract definitions.

See [the architecture](../docs/ARCHITECTURE.md) and [build plan](../docs/BUILD_PLAN.md).
